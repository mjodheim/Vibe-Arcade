# Vibe Arcade — Arcade Log

## 2026-09-15 — The experiment begins

The initial idea was to create several small web games, host them on a VPS, and maintain per-user scoreboards.

The framing then changed: this should not be presented as a traditional coding portfolio. The interesting part is **vibe coding** — exposing a problem or desire to AI, discussing the result, testing it, reacting to it, and iterating until the intended experience emerges.

The first game became **Hivebound: Relics of the Bloom**, a fantasy bee roguelite with selectable roles, procedural maps, loot, crafting, talents, bosses, and leaderboards.

Rather than creating one repository per game, the project moved to a single public monorepo: **Vibe Arcade**. This keeps the complete experiment, future shared platform services, and every game in one observable history.
